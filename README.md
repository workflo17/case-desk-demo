# Case Desk showcase

Case Desk checks a USCIS filing packet before it goes in the mail. It catches the defects that send packets back from the lockbox (a wrong fee, an outdated form edition, a missing signature, the wrong filing address, missing initial evidence) and names each one with the fix and the USCIS page the rule comes from.

This repository holds only the built showcase: https://workflo17.github.io/case-desk-demo/

The showcase runs the real rules engine in your browser against five invented packets. Its guided tour fixes a spouse adjustment packet one defect at a time and shows the attorney sign-off. The packets, names and facts are invented, and nothing here is legal advice. Case Desk is built for licensed immigration attorneys and accredited representatives.
